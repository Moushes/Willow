[How to Install]
│
1. Open PCS Configurator Tool, located at "Tools/Dismay Custom/Penetration Contact System".
│
2. Drag and drop your avatar into the box and setup your preferences.

[Setting Options]
│
Setup Tools
├ Select your installer tool. There are only Modular Avatar and VRCFury.
│
Alignment Preset
├ Select your alignment preset. If there is no available preset for your avatar, please use "Generic" option and do manual adjustment, or select "Reference" to reference target positions from your existing object like SPS sockets.
│
Satisfaction Feature
├ Check to use this feature. Satisfaction Feature comes with Lust Point and Moan Randomizer.
│
Voice Pack
├ Select your voice pack. Choose "Custom" to use your custom prefab  (located inside "/Editor/Resources/Voice Pack/").
│
Lust Multiplier
├ Adjust lust point multiplier. More value = reach orgasm quicker.
│
Custom Target
└ Set your custom target for PCS. This will be the location where PCS attach to when using custom mode. (After applying, you may need to make a little adjustment and correct rotation.)

3. Hit "Apply" to create a PCS prefab. Hit "Replace" to replace an existing PCS prefab with a new one. Hit "Remove" to remove PCS from your avatar.
